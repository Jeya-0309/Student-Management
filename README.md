# Favourite Student List

A simple React application to manage a list of students and add or remove favourite students.

## Live Demo

[View Favourite Student List](https://student-management-weld-kappa.vercel.app/)

## Features

- Display a list of students.
- Add students to favourites.
- Prevent duplicate favourites.
- Remove students from favourites.
- Navigate between pages using React Router.
- Manage global state using Context API.

## Tech Stack

- React JS
- React Router DOM
- Context API
- Tailwind CSS

## Concepts Practised

- useState
- useContext
- createContext
- map()
- filter()
- Conditional Rendering
